# UI fonts

`JetBrainsMono-Variable.woff2` is the unmodified JetBrains Mono variable webfont
from [JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono/tree/19371302b95d218af43299bce79ddbddd0bc364d/fonts/webfonts),
commit `19371302b95d218af43299bce79ddbddd0bc364d`. It is distributed under the
SIL Open Font License 1.1 in `OFL-JetBrainsMono.txt`.

`DepartureMono-Regular.woff2` is the unmodified webfont from the
[Departure Mono v1.500 release](https://github.com/rektdeckard/departure-mono/releases/tag/v1.500).
The font is distributed under the SIL Open Font License 1.1 in
`OFL-DepartureMono.txt`.
