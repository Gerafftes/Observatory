# ESP32-S3-WROOM-Gehäuse

Für die ESP32-S3-Boards ist das externe 3D-Modell
[*ESP32 S3 Wroom Case*](https://makerworld.com/de/models/1456361-esp32-s3-wroom-case#profileId-1517915)
von MakerWorld-Nutzer [`aiekick`](https://makerworld.com/de/@aiekick) vorgesehen.

Das Modell ist laut Quellseite unter der **MakerWorld Standard Digital File
License** veröffentlicht. Diese Lizenz erlaubt keine erneute Bereitstellung
der digitalen Modelldatei auf einer anderen Plattform. Die STL-Datei ist
deshalb nicht Bestandteil dieses Repositories und muss direkt von MakerWorld
bezogen werden.

Die Kompatibilität mit den im Observatory-Aufbau verwendeten Boards muss vor
dem Druck praktisch geprüft werden. Die Ablage dieses Verweises ist kein
Nachweis eines erfolgreichen Drucks oder einer Passprobe.
