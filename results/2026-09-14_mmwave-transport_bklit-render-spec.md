# Bklit render specification — mmWave transport OTA comparison

Render date: 14 September 2026
Source report: [`2026-09-13_mmwave-transport-ota-vergleich.md`](2026-09-13_mmwave-transport-ota-vergleich.md)

## Purpose

Turn the checked before/after table into four repository PNGs without changing
the measurements, denominators, or verdicts. The exports use the same neutral
palette, rounded columns, direct labels, zero-based grids, and compact panel
language as the earlier Bklit result set.

The Bklit chart vocabulary is based on the official [Bklit UI chart
documentation](https://bklit.com/docs/components/bar-chart). The repository
exports are deterministic static PNGs generated by
[`scripts/build_mmwave_transport_bklit.py`](../scripts/build_mmwave_transport_bklit.py);
no new sensor run or threshold change is hidden in the render step.

## Figure mapping

| Output | Bklit chart pattern | Values retained |
|---|---|---|
| `01_ankunft_und_verlust.png` | grouped `BarChart` panels with `Bar`, `BarXAxis`, and `Grid` | raw datagrams, unique arrivals, sequence-loss ratio, duplicate datagrams |
| `02_ankunftslatenz.png` | grouped `BarChart` with separate median/P95 series | arrival median and P95, before versus after |
| `03_serververarbeitung.png` | grouped `BarChart` plus an explicit queue-evidence panel | receive-to-process median/P95; cumulative versus sampled queue evidence kept separate |
| `04_redundanzvergleich.png` | three small grouped `BarChart` panels | one-copy versus two-copy loss ratio, duplicates, and arrival P95 |

## Interpretation safeguards

- Different units are kept in separate panels; no composite “transport score” is
  invented.
- Lower is better for loss, duplicates, latency, and queue growth; the labels
  state this directly.
- Accepted-rate changes remain scene-sensitive. The diagrams emphasize unique
  arrivals, sequence loss, P95, processing time, and duplicates instead.
- The queue panel does not pretend that the old cumulative peak and the new
  sampled maximum are identical measurements.
- The redundancy panel keeps the two-copy trial separate from the three-run
  one-copy aggregate.

## QA

- Four PNGs generated at `1876 × 1294`.
- All plots use zero-based axes and direct value labels.
- Zero duplicate values remain visible as a baseline marker.
- All four images were visually inspected after rendering at full resolution;
  category labels and legends use separate baselines, and no title, axis
  label, value, or footer text is clipped or covered.
- The script is rerunnable and writes only to
  `results/diagrams/mmwave-transport_bklit/`.
